# SVG assets from [theSVG](https://thesvg.org/)

## Thương hiệu (`brands/`)

Logo hãng xe tải từ CDN theSVG:

`https://thesvg.org/icons/{slug}/default.svg`

Nguồn: [glincker/thesvg](https://github.com/glincker/thesvg) — MIT, không bắt buộc attribution.

## Dòng xe (`categories/`)

Icon [Material Design Icons](https://pictogrammers.com/library/mdi/) qua [Iconify](https://iconify.design/) — xem `categories/ATTRIBUTION.md`.

| Slug | Icon |
|------|------|
| `sedan` | car-side |
| `suv` | car-suv |
| `ban-tai` | truck-pickup |
| `xe-dien` | car-electric |

Map trong `src/util/categoryIcons.js`.
